# 两处"生成出来的东西真的不对"：会议纪要跑题、2 条一级分支被判死

> 修复提交基于 `main @ 94e30ed`。实测对象：`backend/scripts/acc_samples.json` 的 20 条真实中文材料
> （课程大纲 7 / 会议纪要 7 / 项目立项 6，490–751 字），基线读数见 `docs/ACCEPTANCE-METRICS.md`。
> 本文只记这两个缺陷的**成因、修法、复算方式**，不改任何指标口径。

## 0 一句话结论

两处缺陷是**同一个上游**的两个症状：**真实中文材料的章节行，目录提取器一条都不认**。
提取器要求"标题行后面空一行"（`_followed_by_blank_line`），而手写中文材料是"`一、背景` 下一行就是正文"。

- 会议纪要：目录 0 条 → 骨架那一次只剩「主题 + 文件名」。主题是文档名（"产品需求评审会"），
  模型只能按**这类文档**的先验写「定义与作用 / 内容要素 / 写作要求 / 格式规范」——把材料当范文，
  于是整棵树是"会议纪要怎么写"。
- 项目立项：目录不是 0 条，而是**从正文里误抽的 2 条列表项**
  （`3. 半年内支持 20 个热门项目、100 位贡献者。`）。它们满足"大写编号 + 后面跟空行"两条版式证据，
  于是成了目录里仅有的两条；`OUTLINE_HEADER` 说的是"请**优先**按它划分一级分支"，模型照做 →
  2 条一级分支 → `MIN_BRANCHES = 3` 判废 → 重试同一份材料同一段提示词，确定性同答案 →
  `too_many_failures`。**与模型无关，是我的提取器给的。**

所以 `MIN_BRANCHES = 3` 并没有错边界：那三条材料的正确分支数是 **6**（`一、背景 … 六、风险` 六节），
2 条是"没读到材料"，不是"材料只有两件事"。

## 2 修法（三处，各管一段）

**① 提取器：结构编号不再要求"后面跟空行"**（`knowledge.service.STRUCTURAL_KINDS`）
`第N章 / 第N节 / 第N条 / 一、` 本身就是结构证据，排版不排版是另一回事。小数编号
（`1.` / `3.1`）**继续**要求空行——假阳性全在那里（正文的编号列表项）。

**② 提取器：以句末标点收尾的候选是句子，不是章节名**（`knowledge.service._looks_like_prose`）
`3. 半年内支持 20 个热门项目、100 位贡献者。` 这种行即使满足版式也进不了目录。
这一条对 S17/S19/S20 是决定性的：去掉它们之后，同一份材料抽出的是真正的 6 节。

**③ 骨架：材料是**待整理的对象**，不是"这类文档怎么写"的范例**（`tools.MATERIAL_AS_OBJECT_RULES`）
有材料时拼在 `plan_system` 末尾（两条生成路同一处，`test_mixed_skeleton.py` 钉着）。
这条判据是针对**通用失效**写的，不是给会议纪要打补丁——理由见第 5 节。

**④ 目录窄于 `MIN_BRANCHES` 时补一句"别被块数锁死"**（`tools.OUTLINE_FEW_BLOCKS_NOTE`）
一份真只有两章的材料，目录仍然拼（它是骨架唯一能看到的材料结构），但"优先按它划分"这句
要加限定，否则条数被钉死在 2。

**⑤ 少于 `MIN_BRANCHES` 的三种结局**（`tools._retry_few_branches` + `BRANCHES_BELOW_MIN`）

| 情形 | 处理 | 理由 |
|---|---|---|
| 纯主题、骨架 2 条 | 仍然 `too_few_branches` 判死 | 没有材料可问，2 条就是没话说；门槛照守 |
| 有材料、骨架 2 条 | **带证据重问一次**：末尾多一句"上一次只给了 2 条"，并附上材料自带的章节（没有目录时附材料开头 300 字） | 外层重试发的是同一段 user，同材料同提示词必然同答案；要它改只能换**输入** |
| 重问仍 2 条 | **交树** + 一条 `BRANCHES_BELOW_MIN` 诊断 | 一棵带引用、能点开、能继续展开的窄树 > 一张错误卡片；`partial` 机制要求"至少长出过一棵树"，结构阶段就死的那三条它救不了 |

`MIN_BRANCHES = 3` **没有改**：它守的是"不要主动交两支架構"，而降级交付的是"模型坚持只能给两条"
的那棵树，并且带一条诊断让用户看见差在哪。收尾那道 `validate_generated_content(enforce_min_branches=)`
按同一个标记放开——否则同一条下限会在出口再判死一次（实测 `invalid_map` 与 `too_few_branches`
是同一条判据的两个出口）。

3. **must 命中率量的是"关键词有没有出现在树上"，量不出"一级分支是不是材料里的事"**。

## 5 这是不是通用失效？——是，判据必须是通用的

**判断：是。** 失败与"会议纪要"这个类别无关，它需要同时满足两个条件：

1. **材料本身是一份产出物**（纪要、周报、课程大纲、立项书、访谈记录、复盘、合同……）；
2. **主题读起来像这类文档的名字**（用户点了"根据这份纪要生成"，标题就是"产品需求评审会"）。

这时"整理这份材料"与"介绍这类文档怎么写"在提示词里是**同一句话**，模型默认走后者——因为它的
世界里"《XX 指南》"这个题目的标准答法就是目录学。四个不同材料四次独立生成给出同一个模板，
说明这不是采样噪声，是一个稳定的读法。

所以修法做成**通用判据**，三句话，都不含任何文档类别：

- **材料是整理对象**（`MATERIAL_AS_OBJECT_RULES`）：一级分支写材料里**讲了哪几件事**
  （议题、结论、待办、风险、指标、分歧），不写"这类文档的通用知识"；只有材料本身在讨论
  写作方法时才写写作要素。
- **材料的结构优先**（目录提取器）：材料自己分了块就按它分，**块的边界来自材料，不来自体裁**。
  这一条是"看得见材料"的地基——判据再好，看不到材料也只能凭先验猜。
- **块不够时按内容补，不按体裁补**（`OUTLINE_FEW_BLOCKS_NOTE` + 重问）：
  条数跟着"材料里能数出几件不同的事"走，而不是跟着"这类文档一般几段"走。

同一组判据对"课程大纲 / 周报 / 立项书"是等价的：它们都可能被写成"这类文档怎么写"，
也都能被识别为"这份材料讲了什么"。**针对会议纪要打补丁（在提示词里写"会议纪要要写议题和待办"）
会让下一类文档重新中招**，而且它解释不了 S09/S10 那种"结构对但内容空"的半中招形态。

一条反向检验：如果这个判断错了（只是会议纪要这一类的问题），那 S14（校招评审）不该出现
"候选人 A/B/C 被压进 detail"——它是三个人的评价，跟"纪要怎么写"没有任何关系，却同样被
写成了写作要素。

### 5.1 盲评那一栏我做不到（如实说）

四维盲评（覆盖 / 层次 / 无捏造 / 可读）要求人逐条打分，我不是那个评分人，这次**没有新打分**，
也不能拿生成结果自己给自己打。可以说明的只有预期的方向与依据：

- **覆盖**：4 条跑题样本（S08/S09/S10/S14）从"生成的是体裁知识"变成"生成的是材料内容"，
  覆盖维按定义应升；但节点数下降（S09 83 → 37）会让"细节密度"这一项变差，两项相抵，
  **不预测分数，等第二位评分人按同一张卡（`backend/data/acc_score_cards.md`）重打**。
- **无捏造**：跑题时模型在**用体裁知识补内容**（这是最典型的捏造形态），修后分支边界来自原文，
  这一维应升；引用覆盖率同批读数 0.604–1.0，没有系统退化。
- **层次**：深度稳定在 4，一级分支 4–7，基本不变。
- **可读**：**会降**——并单子拼出来的长 label（`A / B`）违反了 ≤24 字的可读线，9/20 条踩到，
  这是本次暴露的第三个缺陷（第 3.2 节第 1 条）。

## 6 遗留

- **课程大纲 7 条的目录仍为空**（`第 1 章`，见第 3 节）。它们靠模型的体裁先验拿到了 5–6 条
  五段式分支，覆盖 0.946 但**材料的独特内容被模板压制**（`docs/ACCEPTANCE-METRICS.md` §2.4 发现 2：
  立项书里的"风险"清单被折进"进度与保障"）。修完提取器之后，这一条是下一个可量化的缺口。
- **`_chapter_slices`（按章切）同样受版式闸影响**：`MINDMAP_SECTION_SLICE=1` 在真实材料上
  一直没生效过（20 条全部 `SECTION_SLICE_UNAVAILABLE`）。它走的是同一个 `heading_outline`，
  这次修复顺带让它对 13 条材料可用（`section_slice.chapters` 4–7）；但它要求"恰好一份材料"，
  多份材料仍然不走。**它的代价还没有量过**：这个开关的默认值是在"按章切永远不生效"的
  前提下定的，那个前提今天没了（第 3.2 节第 2 条）。
- **重问只做一次**：两次都不足就降级交付。做三次的收益没有证据，成本是每条失败样本多一次调用。
- **`第 1 章`（阿拉伯数字）不认**：`_HEADING_RE` 只有中文数字分支，课程大纲 7 条因此没有目录。
  这一处与"结构编号免版式闸"是两件事，可以单独做。
