1. **共同基础**：RPeGio 与陈嘉涛共同确定 JSON、接口、代码规范和分支规则（`main` ← `dev` ← `feat/*`，PR 目标 `dev`，中文 Conventional Commits）。先在本人电脑启动当前骨架，验证演示模式生成与读取。

3. **多模态与优化（进行中）**：陈嘉涛做文档、图片、语音接入及逻辑建议（F05–F08 于 2026-11-04/05 落地，F15/F16 部分落地）；RPeGio 做样式、布局、预览与建议确认。混合输入已可用；节点来源引用界面已于 2026-11-07 补齐（`fc8f82f`），下一个界面任务是结构诊断面板（F15）。
